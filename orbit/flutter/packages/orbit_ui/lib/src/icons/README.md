# Orbit icons

`orbit_icons.dart` is generated by `orbit/flutter/tools/gen_orbit_icons.py`;
do not edit it by hand. `--check` fails when it is out of date.

## What it holds

Every Phosphor icon the prototype draws: each `ph-<name>` class in
`prototype/js` and `prototype/index.html`, plus each quoted name that is a
Phosphor icon, because the prototype passes most names through variables and
ternaries (`on ? 'eye-slash' : 'eye'`). A few quoted words that are not icons
there (`'video'`, `'lock'`) come along; unused constants are tree-shaken.

Each icon is an `OrbitGlyph` with all five weights as `const IconData`
(regular, light, bold, fill, and duotone with its faded back layer). The code
points come from phosphor_flutter 2.1.0's generated tables in the pub cache;
the fonts are bundled in `orbit_ui/fonts/phosphor/` (MIT, licence beside
them). The flat weights share code points.

## How a weight is chosen

The prototype's rule (`prototype/js/ui.js`, `icon()`): a call site may name a
weight; otherwise the theme's applies (regular for Orbit and Night, light for
Bloom, Papyrus and Terminal, bold for Arcade and Field, duotone for Mochi).
`OrbitIcon(glyph, weight: ...)` does the same: pass `weight` only where the
prototype writes one (`icon('check', 'bold')`, or a hard-coded
`<i class="ph ph-plus">`, which is regular in every theme).

Duotone draws the back layer at 20% under the outline, as Phosphor's web font
does.
