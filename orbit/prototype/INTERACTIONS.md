# Orbit interactions

GENERATED by `tools/manifest.py` from the prototype. Do not edit by hand:
change the `interactions` list next to the screen in `js/screens/*.js`, the
app frame's list in `js/app.js`, or the kit's list in `js/kit.js`.

Each item is a behaviour the Flutter port must have. Tick it when its
widget test passes. Gestures: auto, drag, hold, key, long-press, right-click, scroll, swipe, swipe-left, swipe-right, tap, type.

## Every screen (the app frame)

- [ ] **tap** Back arrow: Returns to the previous page; on a window, in the same pane.
- [ ] **key** Esc: Closes the topmost thing: a menu or sheet, then a call or the viewer, the info pane, the right pane. *(window only)*
- [ ] **key** Esc: Goes back, like the back arrow. *(phone only)*
- [ ] **tap** Outside a sheet, menu or dialog: Closes it.
- [ ] **tap** Menu or sheet row: Runs it and closes the menu or sheet.
- [ ] **tap** Undo on a toast: Undoes what the toast reported.
- [ ] **auto** Toast: Disappears after 2.8 s.
- [ ] **tap** A row, tile or chat in the list pane: Replaces what the right pane shows; it stays marked in the list. *(window only)*
- [ ] **auto** Right pane: Remembers its page for each list (Chats, Calls, You) and brings it back. *(window only)*
- [ ] **auto** Info pages (contact, group, media, chat settings, message info): Open beside the chat from 1200 px, over it below. *(window only)*
- [ ] **auto** Menus: Hang from the button that opened them. *(window only)*
- [ ] **auto** Sheets: Open as centred dialogs; a sheet from the composer pops up above its button. *(window only)*
